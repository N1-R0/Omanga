## Reporting back

When a task is done, say it is done and list what changed in a few short lines.

- No long explanations, no rationale essays, no recaps of steps already watched.
- Do not present or link files. They are visible in the IDE.
- Decisions, trade-offs and deviations go in code comments and `design.md`, not
  in the chat reply.
- Only surface something in chat when it needs a decision or is a blocker.
